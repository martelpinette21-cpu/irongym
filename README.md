# IronGym — Forge Your Strength

Single-page website for IronGym, a strength-focused gym. Dark industrial theme, fully responsive, zero dependencies — one HTML file with inline CSS/JS.

## Features

- **Hero** — bold headline, gym stats, CTAs
- **Programs** — Powerlifting, Hypertrophy, Conditioning, Fight Prep, 1-on-1 Coaching, 24/7 Open Gym
- **Pricing** — Day pass / Monthly / Annual tiers
- **Class schedule** — responsive weekly table
- **Contact footer** — address, phone, email, hours
- Mobile hamburger menu + scroll-reveal animations

## Run locally

Just open `index.html` in a browser. No build step, no dependencies.

## Deploy on GitHub Pages

1. Go to **Settings → Pages**
2. Under **Source**, select `main` branch, `/ (root)`
3. Save — your site goes live at `https://martelpinette21-cpu.github.io/irongym/`

## Customize

- Colors: edit the CSS variables in `:root` (`--accent`, `--accent2`, `--bg`, etc.)
- Content: pricing, schedule, and contact details are plain HTML — search for the section comments (`<!-- PRICING -->`, etc.)
